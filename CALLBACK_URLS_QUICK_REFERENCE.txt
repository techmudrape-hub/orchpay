================================================================================
MONEYONE - PAYMENT GATEWAY CALLBACK URLs
================================================================================

PROVIDE THESE URLs TO YOUR PAYMENT GATEWAY PROVIDERS:

--------------------------------------------------------------------------------
MUDRAPE PAYMENT GATEWAY
--------------------------------------------------------------------------------

Payout Callback (Settlements/Withdrawals):
URL: https://api.orchpay.in/api/callback/mudrape/payout
Method: POST
Format: JSON

Payin Callback (Collections/Deposits):
URL: https://api.orchpay.in/api/callback/mudrape/payin
Method: POST
Format: JSON

--------------------------------------------------------------------------------
PAYU PAYMENT GATEWAY
--------------------------------------------------------------------------------

Payout Webhook:
URL: https://api.orchpay.in/api/payu/webhook/payout
Method: POST
Format: JSON

Payin Success Callback:
URL: https://api.orchpay.in/api/payin/callback/success
Method: POST
Format: Form Data

Payin Failure Callback:
URL: https://api.orchpay.in/api/payin/callback/failure
Method: POST
Format: Form Data

--------------------------------------------------------------------------------
IMPORTANT NOTES:
--------------------------------------------------------------------------------

1. All URLs use HTTPS (SSL enabled)
2. Callbacks are already implemented and active
3. System handles duplicate callbacks automatically (idempotent)
4. Logs are available at: /var/log/moneyone/error.log
5. Test callbacks before going live
